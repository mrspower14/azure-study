5. 채팅 입력 창 옆 [추적] 버튼을 클릭해 에이전트의 도구 호출 이력 확인



== vscode 에서 실행 ==

6. VS Code의 액션 바에서 [확장]-[Foundry Toolkit for VS Code] 선택 (필요시 설치)
- 필요시 Azure 확장에서 로그인

7. Foundry Toolkit 창에서, Microsoft Foundry Resource 확장 후 [Set Default Project] 클릭 후 앞서 만든 Foundry 프로젝트 선택

8. Foundry Toolkit 창에서,[My Resource] 아래의 프로젝트를 확장하고 [Agents]를 선택한다.

9. [Agents]-[Prompt Agents] 아래에서 aiinfra-agent를 선택하면, [Agent Builder] 탭이 열린다.

10. 플레이그라운드의 [Model] 항목을 friday로 선택한다.

11. 플레이그라운드의 채팅 창에서 다음 프롬프트를 입력하고 결과를 검토한다.
프롬프트: 기기 분실 또는 도난 신고에 관한 정책은 어떻게 되나요?

[에이전트와 상호작용하는 애플리케이션 만들기]
12. .env 파일 만들고 프로젝트 엔드포인트와 에이전트 이름 업데이트
    에이전트 -> 오른쪽 버튼 -> copy to endpoint 
    
13. 필요한 패키지 설치 (ai_agent 폴더 이동 )
npm install @azure/ai-projects @azure/identity dotenv

14. 애플리케이션을 실행해 다음의 프롬프트를 입력하여 다양한 기능 테스트
node .\friday-using-agent.js
